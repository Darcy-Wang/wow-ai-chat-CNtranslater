# Windows 实机验收清单

以下为待执行的验收步骤，不能视为已通过。自动测试中的模拟接口不验证真实服务质量或游戏画面。

| 场景 | 操作与通过条件 |
|---|---|
| 干净环境 | Windows 10/11 x64、Python 3.11；安装锁定依赖，测试通过；EXE 在未安装 Python 的用户环境可启动 |
| 原生凭据 | 保存测试 Key 后，配置 JSON 中 Key 为空；重启后可读取；清空并保存后凭据被删除 |
| 老配置迁移 | 备份旧配置；首次启动读取原设置；保存后旧明文 Key 清空，新用户配置存在；旧文件只读时准确提示失败 |
| 保存失败 | 用户配置只读或损坏时明确提示，不显示保存成功，不覆盖损坏文件；修复后重启恢复 |
| OCR 预览 | 100%、150%、200% 缩放分别框选和识别；实际截图对应所选聊天文字；检查框选器保存区域 |
| 多屏 | 主屏和负坐标副屏分别测试；混合缩放时坐标正确或给出无法映射的提示；拒绝跨屏区域 |
| 游戏窗口 | 窗口化、无边框模式分别验证置顶和穿透；独占全屏单独记录结果；移动游戏窗口后重新框选 |
| 防自识别 | 捕获区域与悬浮窗重叠时暂停；移动悬浮窗后恢复，不循环翻译自身内容 |
| 指令准确性 | 连续出现 pull in 5、pull in 15、pull in 1.5、don't pull、do pull；均保留并各自正确翻译 |
| 重复消息 | 同一玩家再次发送 oom/lust；两次均展示；OCR 同帧不重复；聊天滚动后保留新增发言 |
| 频道语言 | 实际客户端副本/副本向导、小队、团队、密语均可识别；中英混合被翻译；未知频道选项生效 |
| 网络退化 | 测试接口超时、429、401；状态可见、没有自动重试风暴；表格保持响应，旧译文不继续弹出 |
| 队列与顺序 | 模拟第一条慢、第二条快，按采集顺序展示；突发流量受容量限制，过时及丢弃计数可见 |
| 停止重启 | 请求途中停止并重新开始；旧捕获信号和旧译文不串入新会话；修改 API/过滤设置后新消息仍正常进入 |
| 退出 | OCR 初始化/请求执行中关闭，界面显示等待后台任务结束，不发生 QThread 销毁崩溃 |
| 长时间运行 | 连续捕获至少 2 小时；主表格≤500、悬浮窗≤60、控制台≤1000块；记录内存、CPU、端到端 P50/P95 |
| 发布配置 | 本机放置带测试 Key 的 config.json；构建后发布包仅有空白 Key；重复构建能覆盖旧发布配置 |
| 插件 | 在目标 Retail/Classic 具体版本检查加载、/wct status/on/off；记录客户端 build 和插件 Interface 匹配情况 |

性能记录应包括 CPU/GPU、分辨率/缩放、捕获尺寸、OCR 间隔、模型、接口所在地、消息速率和样本量。端到端统计不包括游戏写日志前的缓冲等待或消息出现到下一次截图的轮询等待，不提供未经测量的固定延迟承诺。
